# Тест-кейсы ServiceDesk API

## 1. Общая информация

Тестирование проводится для проверки корректности работы REST API системы ServiceDesk.

## 2. Тест-кейсы

### 2.1. Клиенты (Clients)

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| TC-01 | Получение списка клиентов | Возвращается список клиентов, код 200 |
| TC-02 | Получение существующего клиента по ID | Возвращаются данные клиента, код 200 |
| TC-03 | Получение несуществующего клиента | Возвращается ошибка 404 |
| TC-04 | Создание клиента | Клиент сохраняется в БД, код 201 |
| TC-05 | Обновление существующего клиента | Данные клиента обновляются |
| TC-06 | Удаление клиента, связанного с оборудованием | Удаление отклоняется, код 409 |
| TC-07 | Удаление несуществующего клиента | Возвращается ошибка 404 |

### 2.2. Оборудование (Equipment)

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| TC-08 | Получение списка оборудования | Возвращается список оборудования, код 200 |
| TC-09 | Получение оборудования по ID | Возвращаются данные оборудования, код 200 |
| TC-10 | Получение несуществующего оборудования | Возвращается ошибка 404 |
| TC-11 | Создание оборудования | Оборудование сохраняется в БД, код 201 |
| TC-12 | Обновление оборудования | Данные оборудования обновляются |
| TC-13 | Удаление оборудования, связанного с заказом | Удаление отклоняется, код 409 |
| TC-14 | Удаление несуществующего оборудования | Возвращается ошибка 404 |

### 2.3. Заказы на ремонт (Orders)

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| TC-15 | Получение списка заказов | Возвращается список заказов с информацией об оборудовании и клиентах |
| TC-16 | Получение заказа по ID | Возвращаются данные заказа |
| TC-17 | Получение несуществующего заказа | Возвращается ошибка 404 |
| TC-18 | Создание заказа | Заказ сохраняется в БД |
| TC-19 | Обновление заказа | Данные заказа обновляются |
| TC-20 | Удаление заказа со связанными записями | Удаление отклоняется, код 409 |
| TC-21 | Удаление несуществующего заказа | Возвращается ошибка 404 |

### 2.4. Сотрудники (Employees)

### 2.6. Запчасти (Parts)

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| TC-28 | Получение списка запчастей | Возвращается список запчастей с ценами и складскими остатками |

### 2.7. Запчасти в заказах (Order Parts)

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| TC-29 | Получение запчастей заказа | Возвращается список запчастей, связанных с заказом |
| TC-30 | Получение запчастей заказа без добавленных позиций | Возвращается пустой список |
| TC-31 | Добавление запчасти в заказ | Создается запись, складской остаток уменьшается |
| TC-32 | Удаление запчасти из заказа | Запись удаляется, количество возвращается на склад |

### 2.8. Платежи (Payments)

| TC-35 | Получение несуществующего платежа | Возвращается ошибка 404 |
| TC-36 | Создание платежа | Платеж сохраняется в БД |

## 3. Результаты тестирования

В ходе проверки API через Swagger UI были проверены основные операции получения, создания, обновления и удаления данных.

Также проверена обработка отсутствующих ресурсов, ограничений на удаление связанных записей и изменение складских остатков при добавлении и удалении запчастей.
